# Tansakusha Collection ☺
> 本拡張機能は、OpenAIのChatGPTによるコード作成・デバッグ対応を利用して開発しています。
> この開発方法についてご自身の考えと合わない場合は、本拡張機能の使用をお控えください。
> 生成されたコードは実際に動作確認を行い、権限・通信先・静的解析についても確認しています。
> 使用した外部ツールと確認結果は、下記「コード・セキュリティ確認」に記載しています。

> [プライバシーポリシー](PRIVACY.md)

**クトゥルフ神話TRPG 6版 / 7版の探索者を、Chrome上でまとめて管理するための拡張機能です。**

Charaeno・いあきゃら・ココフォリアから探索者情報を取り込み、能力値・技能・SAN・画像などを一覧で確認できます。

現在のバージョン：**v0.6.28**

---

## 主な機能

- CoC 6版 / 7版に対応
- 探索者をカード形式で一覧表示
- CharaenoのキャラクターシートURLから取り込み
- いあきゃらのココフォリア駒データから取り込み
- ココフォリアでコピーした駒を直接取り込み
- 探索者名・ルビで検索
- 技能名で検索
- 技能値の高い順に並び替え
- 上位3名を王冠表示
- STATUS / SKILL の表示・非表示
- 探索者ごとのSTATUS / SKILL伏せ
- SANの手動修正
- 探索者名・ルビ・Webカラーの編集
- 最終更新日の表示
- 探索者データと保存画像のバックアップ / 復元

---

## データの統合ルール

同じ探索者を別の取り込み元から更新した場合、原則として1枚のカードへ統合します。

### 技能
現在値と新しく取り込んだ値を比較し、**高い方を保持**します。

新しい技能は追加されます。

### SAN
キャラクターシートを再取り込みしても、現在のSANを維持します。

ココフォリアの駒から取り込んだ場合は、駒側のSANを利用できます。

### HP / MP
取り込まれた最新の値で更新します。

### 画像
ココフォリア由来の画像を優先して保存します。

取得した画像は拡張機能内部の **IndexedDB** に保存されます。

---

## ココフォリアから取り込む方法

1. 同じChromeプロフィールでココフォリアの部屋を開く
2. 取り込みたいコマを右クリックしてコピー
3. Tansakusha Collectionを開く
4. 「ココフォリア」から6版または7版を選択
5. 表示された探索者名を確認して取り込む

取り込み操作をした時だけ、最後にコピーされたコマの情報を読み取ります。

**部屋内のコマやココフォリア側の保存データを書き換えることはありません。**

---

## データの保存について

探索者データは **`chrome.storage.local`** に保存されます。

画像はChrome拡張機能内部の **IndexedDB** に保存されます。

原則として、探索者一覧をTansakusha Collection独自の外部サーバーへ送信する処理はありません。

PCやChromeプロフィールを変更すると保存領域も変わるため、移行前に「バックアップ保存」を使用してください。

---

## 通信について

機能上必要な場合のみ、以下のサービスへアクセスします。

- `ccfolia.com`
- `storage.ccfolia-cdn.net`
- `charaeno.com`
- `object-storage.tyo2.conoha.io`
- `image.iaproject.app`

主な用途は、キャラクターシート情報や探索者画像の取得です。

Google Analyticsなどのアクセス解析、広告SDK、独自のトラッキングサーバーは使用していません。

---

## Chrome権限

### `storage`

探索者データや表示設定をブラウザ内に保存するために使用します。

### `clipboardWrite`

カードの「Copy」機能で探索者名をクリップボードへコピーするために使用します。

### `scripting`

ユーザーがココフォリア取り込みを実行した時に、開いている `ccfolia.com` のタブから最後にコピーされたコマを読み取るために使用します。

常時ページを監視するためのものではありません。

## インストール方法

1. このリポジトリをダウンロード
2. Chromeで `chrome://extensions/` を開く
3. 「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」を選択
5. `manifest.json` が入っているフォルダを指定

---

## 更新するとき

更新前にTansakusha Collection上部の **「バックアップ保存」** を使用することをおすすめします。

現在Chromeが読み込んでいる拡張機能フォルダへ新しいファイルを上書きし、

`chrome://extensions/`

からTansakusha Collectionを再読み込みしてください。

保存データを維持したい場合は、むやみに拡張機能を削除して入れ直さないでください。

## コード・セキュリティ確認

v0.6.28では、以下のツール・方法で確認を行いました。

- **Extension Preflight**
  - Chrome拡張機能のパッケージ構成・権限などを確認
  - 9項目すべて問題なし

- **ESLint Playground**
  - JavaScriptの構文・未定義参照・未使用コードなどを確認
  - 致命的な構文エラーなし
  - 未使用変数や空の `catch` など、軽微な改善点を確認

- **ExtGuard**
  - Chrome Web Store向けの権限・ポリシー・構成チェック
  - 致命的：0件
  - 合格：20件
  - 警告：4件
  - 警告内容は主にストア掲載情報・権限説明・プライバシーポリシーに関するもの
  - 警告内容は、権限説明、プライバシーポリシーURL、権限宣言の自動判定、ストア説明文に関するものでした。

- **Chrome DevTools / Network**
  - 実際の動作中に発生する通信を確認
  - 通常閲覧時に不要な外部Fetch通信が発生しないことを確認
  - Charaeno取り込み時はCharaeno関連への通信を確認
  - ココフォリア取り込み時は `storage.ccfolia-cdn.net` からの画像取得を確認
　- 今回確認した操作範囲では、不明な第三者サーバーへの探索者データ送信は確認されませんでした。
念入りに確認はしていますが、これらの確認は安全性を完全に保証するものではありません。
ご利用の際は、ご自身の環境で動作をご確認ください。
